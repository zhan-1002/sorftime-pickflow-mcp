# ASIN 评估体系：从三元判断到九维加权

> 日期：2026-07-25 | 基于 97 个已知好 ASIN 反向验证

---

## 一、演进历程

### 1.0 — 六维 G/Y/R（初版）

```
每个维度独立判断: 🟢绿灯 / 🟡黄灯 / 🔴红灯
通过标准: 4绿0红
```

**问题**：
- 上架 >180 天 = 🔴 → 53/97 个已知好 ASIN 被误杀
- 广告 >60% = 🔴 → 新品正常广告期被惩罚
- 评论 32 vs 评论 98 同为 🟡，没有区分度
- 无法回答"这个 ASIN 比那个 ASIN 好多少"

### 1.1 — 去掉新品硬门（修正版）

```
改动: 上架天数从 RED 改为加分项
结果: 25.8% → 62.9% 通过率
```

**问题**：剩余 37% 的失败者中，很多在其他维度是优秀的，但被广告/评论的一刀切淘汰。

### 2.0 — 九维加权评分（当前版）

```
9 个维度 × 差异化权重 → 0-100 总分
S ≥ 70 | A 55-69 | B 40-54 | C < 40
```

**结果**：S+A 覆盖 79.4%，S+A+B 覆盖 99%。

## 四、关键设计决策

### 上架天数从 RED → 增长势能

旧体系：上架 >180 天直接红灯淘汰。
新体系：上架 × 日销交叉评分。

```
上架 ≤90天 + 日销 ≥1   → 10分 (新品起飞)
上架 ≤90天 + 日销 <0.3  → 8分  (新品起步)
上架 ≤180天 + 日销 ≥1  → 9分  (中期高增长)
上架 ≤180天 + 日销 <0.3 → 7分  (中期增长)
上架 ≤365天 + 日销 ≥3  → 8分  (一年内爆发)
上架 ≤365天 + 日销 ≥1  → 6分  (一年内稳定)
上架 >365天 + 低销量     → 4分  (老品滞涨, 不淘汰但低分)
```

### 广告从 G/Y/R → 有机流量百分比

旧体系：广告 >60% = 🔴，新品广告期正常行为被惩罚。
新体系：有机流量百分比连续评分，不设硬门——90%有机=10分，30%有机=4分。

新品高广告但高增长的 ASIN（如 [ASIN-R5]，Bible Cover，90%广告，72天上架，月销118）在新体系是 68 分 A 级，旧体系直接🔴淘汰。

### 评论从 G/Y/R → 进入壁垒

旧体系：评论 ≤30 = 🟢，≤100 = 🟡，>100 = 🔴。
新体系：评论越少壁垒越低，得分越高。但评论多不直接淘汰——和利润/增长等其他维度互补。

[ASIN-R6]（Giant Friendship Bracelet，129 评，日销 0.4，85% 利润率）：旧体系评论🔴淘汰，新体系虽评论壁垒 3 分但利润 10 分+有机 10 分，总分 61 A。

## 五、与旧体系的关键差异总结

| | 六维 G/Y/R | 九维加权 |
|---|---|---|
| 判断方式 | 三元（过/黄/死） | 0-10 连续分 × 权重 |
| 维度数 | 6 | 9 |
| 上架天数 | >180天=🔴淘汰 | 和日销交叉算增长势能 |
| 广告 | >60%=🔴淘汰 | 有机%连续评分 |
| 评论 | >100=🔴淘汰 | 壁垒越低分越高，但不淘汰 |
| 可比较性 | 不能比"谁更好" | 总分可排序 |
| 短板可视化 | 不知道弱在哪 | 每维分数清晰 |
| 覆盖率(S+A) | 25.8% → 62.9% | **79.4%** |
| 误杀率 | 高（新品/广告期误判） | 低（无硬门，短板只扣分） |
